# Evidências de Execução do Dashboard (Apache Superset)

Esta pasta foi reservada para o armazenamento de capturas de tela e evidências visuais do dashboard em execução no Apache Superset, conforme a seção 11 do edital do Desafio Prático 1.

### Evidências Recomendadas:
1. `dashboard_visao_geral.png`: Captura da tela inteira do painel apresentando os 5 cartões executivos e os 2 gráficos (linhas e barras);
2. `dashboard_filtros_interativos.png`: Captura demonstrando o comportamento dinâmico ao aplicar o filtro de período e o filtro de categoria temática;
3. `superset_conexao_database.png`: Captura da tela de conexões de banco de dados (`Settings -> Database Connections`) validando a conexão com o PostgreSQL.
